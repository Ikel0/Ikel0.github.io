# Publications

Le fil est alimenté par `posts.js`.

1. Ajouter un objet dans le tableau `posts` avec un titre, une date, une catégorie, un résumé, des tags et un lien.
2. Pour une publication longue, créer une page HTML dans ce dossier et utiliser son nom dans `href`.
3. Pour un média, placer le fichier dans `notes/media/` puis ajouter l’objet `media` indiqué en commentaire dans `posts.js`. Les images, vidéos MP4 et intégrations externes sont pris en charge.

Les catégories disponibles dans le filtre sont `note`, `build` et `demo`.
